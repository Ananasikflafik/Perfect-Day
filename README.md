# Monkey My Day
##What is it?
Monkey My Day is a desktop pet that helps users track their daily tasks to help them have a perfect day. This app uses an incetive system too keep users engaged and promotes mental health through daily challenges and journaling.

##How it was made
This website was coded with HTML, JavaScript and CSS. The background art and characters were modified in Canva using various artworks from Pintrest.

##How to play
Complete tasks to earn bananas and unlock diffrent maps and skins.
